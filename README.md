# stage-2-backend-api

## About

The Radiology PACS Backend API is a RESTful server application designed to support radiology imaging workflows. The API provides secure user authentication and access to radiology-related resources while integrating with FDA device information.

This project was built using Node.js, Express, MongoDB, and Mongoose following REST API development best practices.

## Features

User registration and authentication
JWT-based authorization
Secure password hashing with bcryptjs
Protected API routes
MongoDB database integration with Mongoose
FDA device search functionality
Request validation using Celebrate and Joi
Centralized error handling
RESTful API architecture
